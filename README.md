# مصحف قالون

تطبيق مصحف برواية **قالون عن نافع**: أنيق، بسيط، مجاني، **بدون إعلانات ولا تتبّع**، ويعمل دون إنترنت. يعمل على أندرويد وآيفون (Expo / React Native).

## المزايا
- عرض المصحف صفحةً صفحة (٦٠٤ صفحة) بالتمرير يمينًا ويسارًا كالمصحف الورقي، مع ترويسة السور والبسملة وعلامات الآيات.
- فهرس السور (مكية/مدنية، عدد الآيات بعدّ المدني الأول) وفهرس الأجزاء.
- بحث سريع يتجاهل التشكيل واختلاف الرسم (مثلًا اكتب `كرسيه`)، وبحث باسم السورة.
- علامات مرجعية: اضغط مطولًا على أي آية لحفظها أو نسخها أو مشاركتها.
- متابعة القراءة من آخر صفحة تلقائيًا.
- ثلاثة مظاهر: فاتح، ورقي، ليلي (أو تلقائي حسب الهاتف)، وتكبير/تصغير الخط، وإبقاء الشاشة مضاءة.

## التشغيل على الهاتف (أسرع طريقة)
1. ثبّت [Node.js](https://nodejs.org) (LTS) على الكمبيوتر، وثبّت تطبيق **Expo Go** على الهاتف من المتجر.
2. في مجلد المشروع:
   ```bash
   npm install
   npx expo start
   ```
3. امسح رمز QR الذي يظهر بتطبيق Expo Go (أندرويد) أو بالكاميرا (آيفون). يجب أن يكون الهاتف والكمبيوتر على نفس شبكة الواي فاي.

## بناء ملف APK للتثبيت الدائم (أندرويد)
```bash
npx eas-cli@latest login         # حساب Expo مجاني
npx eas-cli@latest build -p android --profile preview
```
بعد انتهاء البناء على خوادم Expo يظهر رابط لتنزيل ملف APK وتثبيته على الهاتف.

## المصادر والتراخيص
- نص المصحف (رواية قالون، الإصدار ١٠) وخط `qaloon.10.ttf` من **مجمع الملك فهد لطباعة المصحف الشريف** (KFGQPC) عبر [quran-data-kfgqpc](https://github.com/thetruetruth/quran-data-kfgqpc). الخط مرخّص للاستخدام المجاني من المجمع ولا يجوز تعديله.
- `scripts/build-data.py` يحوّل ملف JSON الأصلي إلى `src/data/quran.json`.
- `scripts/make-icons.py` يولّد أيقونة التطبيق.
